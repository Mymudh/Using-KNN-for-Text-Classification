# Using KNN for Text Classification

## Overview
This project demonstrates text classification using the K-Nearest Neighbors (KNN) algorithm and Python. It explores how machine learning can classify text data based on similarities between data points.

## Objectives
- Understand the K-Nearest Neighbors algorithm.
- Apply machine learning techniques to text classification.
- Preprocess text data for model training.
- Train and evaluate a KNN classification model.
- Analyze model performance using evaluation metrics.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Algorithm
K-Nearest Neighbors (KNN) is a supervised machine learning algorithm that classifies a data point based on the labels of its nearest neighbors.

## Project Workflow
1. Import the required Python libraries.
2. Load the dataset.
3. Preprocess and clean the text data.
4. Convert text into numerical features.
5. Split the dataset into training and testing sets.
6. Train the KNN classifier.
7. Make predictions.
8. Evaluate model performance.

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix
